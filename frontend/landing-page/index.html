FAQ

Perguntas frequentes

Como funcionam os planos do FluxMEI?

Você começa com 7 dias grátis para testar todos os recursos e depois escolhe entre o plano Pro Mensal de R$ 49,90 ou o plano Pro Anual por R$ 39,90/mês, cobrado anualmente.

Preciso instalar alguma coisa?

Não. O FluxMEI roda pelo navegador e pode ser acessado pelo computador ou celular. Futuramente, também teremos uma versão instalável do app.

Meus dados ficam seguros?

O projeto usa autenticação e estrutura de dados moderna, com foco em acesso protegido.

O FluxMEI substitui um contador?

Não. Ele ajuda na organização financeira, mas não substitui orientação contábil profissional.

Posso usar pelo celular?

Sim. A interface é responsiva e preparada para uso mobile.

Vai ter versão desktop?

A base web já funciona no computador. Uma versão desktop pode ser disponibilizada futuramente.
